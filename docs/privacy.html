Privacy Policy

DHARM Upload Manager · Last updated: November 2026

What this app does

DHARM Upload Manager is a tool that, with the channel owner's permission (Google OAuth), takes videos from Google Drive, uploads and schedules them on the owner's own YouTube channels, and shows analytics.

What data is used

  • YouTube Data API v3: uploading videos, setting title/description/tags, channel info.
  • YouTube Analytics API: aggregate numbers such as views, watch time and subscribers.
  • Google Drive API: reading video files only from configured folders, and moving a file to Trash after a verified upload (never a permanent delete).
  • Gemini API: writes the title, description and hashtags. The video file being uploaded is sent to Gemini (Google) so it can describe it; Gemini files are deleted after use. No other personal data is sent.

Where data is kept

  • OAuth tokens are stored encrypted (Fernet), only in the owner's own backend database.
  • This dashboard (GitHub Pages) is a static website. It contains no secrets, tokens or private data.
  • The dashboard saves only two things in your browser: the backend URL (localStorage) and the login session token (sessionStorage — removed as soon as you close the tab).
  • The service worker caches only the app files (HTML/CSS/JS/icons); API responses are never cached.

Sharing

Data is never sold or shared with third parties. Google APIs are used in line with the Limited Use rules of the Google API Services User Data Policy.

Revoking permission

You can remove this app's permission at any time from Google Account → Third-party access. You can also ask the owner to delete your channel and its encrypted tokens from the backend.

Contact

For questions, open an issue in the repository's GitHub Issues.
