Privacy Policy

DHARM YT PRO · Last updated: November 2026

Yeh app kya karta hai

DHARM YT PRO ek private tool hai jo channel owner ki permission (Google OAuth) se Google Drive se videos lekar unke apne YouTube channels par upload, schedule aur analytics dikhata hai. Yeh public service nahi hai.

Kaunsa data use hota hai

  • YouTube Data API v3: video upload, title/description/tags set karna, channel info.
  • YouTube Analytics API: views, watch time, subscribers jaise aggregate numbers.
  • Google Drive API: sirf configured folders se video files padhna, aur verified upload ke baad file ko Trash mein bhejna (permanent delete kabhi nahi).
  • Gemini API: title/description/tags ke suggestions. Sirf aapke diye notes/file name bheje jaate hain.

Data kahan rehta hai

  • OAuth tokens encrypted (Fernet) form mein sirf owner ke apne backend database mein rehte hain.
  • Yeh dashboard (GitHub Pages) ek static website hai. Isme koi secret, token ya private data nahi hota.
  • Dashboard aapke browser mein sirf do cheezein save karta hai: backend URL (localStorage) aur login session token (sessionStorage — tab band karte hi hat jaata hai).
  • Service worker sirf app ki files (HTML/CSS/JS/icons) cache karta hai; API responses kabhi cache nahi hote.

Sharing

Data kisi third party ko becha ya share nahi kiya jaata. Google APIs ka use Google API Services User Data Policy ke Limited Use rules ke hisaab se hota hai.

Permission wapas lena

Aap kabhi bhi Google Account → Third-party access se is app ki permission hata sakte hain. Owner se kehkar apna channel aur uske encrypted tokens backend se delete bhi karwa sakte hain.
